# Contributing Guidelines

## Overview
Contributions are welcome via pull requests on GitHub. Please follow the guidelines below
to ensure consistency and maintainability.

## Workflow

1. Fork the repository.
2. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Implement your changes.
4. Run tests with `pytest` and confirm all pass.
5. Commit changes with descriptive messages.
6. Open a pull request against `main`.

## Coding Standards

- Follow PEP 8 for Python code style.
- Include docstrings for all public functions and classes.
- Add or update unit tests for any new code.

## Documentation

All new features should include updates to relevant Markdown files under `/docs`.
