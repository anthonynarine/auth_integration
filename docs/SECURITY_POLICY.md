# Security Policy

## Supported Versions

| Version | Supported |
|----------|------------|
| 0.3.x (current) | Yes |
| < 0.3.0 | No |

Only the latest `0.3.x` release is actively supported — consumers should track the current tag/commit in their `requirements.txt` rather than pinning an old one indefinitely. See the root `README.md`'s "Releasing a new version" section for the update process.

## Reporting a Vulnerability

To report a security issue, contact **Anthony Narine** via GitHub or the email
address listed in the repository profile. Include detailed reproduction steps
and environment information.

Reports are reviewed within 72 hours, and confirmed issues will be fixed promptly.
