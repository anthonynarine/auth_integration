# Security Policy

## Supported Versions

| Version | Supported |
|----------|------------|
| 2.x | Yes |
| 1.x | No |

## Reporting a Vulnerability

To report a security issue, contact **Anthony Narine** via GitHub or the email
address listed in the repository profile. Include detailed reproduction steps
and environment information.

Reports are reviewed within 72 hours, and confirmed issues will be fixed promptly.
